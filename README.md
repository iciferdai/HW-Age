# HW-Age
> 数据分析探索实践项目

:warning: **免责声明：所采用的数据均源于互联网公开信息源，不涉及任何敏感数据；所做的假设与分析，均为娱乐实践，分析结果不准确且不具备参考性，项目本身仅做为一个数据分析的Case，用作学习交流以及娱乐互动**


## 一. 项目介绍
某企业连续多年发布年度报告及可持续发展附录，其中可持续发展附录中包含了企业的员工数量及分年龄段的占比
但该报告中的年龄段，并没有细分到业界广大网友真正关心的35+问题
那么是否可以通过数据分析的方法，基于一些假设和条件，来尝试做一些推测呢？

### 4. 计算方法
> :warning:  提醒：计算方法是基于假设条件成立，但实际假设条件不为真，且带来的误差不可忽略  

企业员工随报告年度时间，与年龄自然增长之间的关系示意图：
![method2](https://github.com/iciferdai/HW-Age/blob/main/pictures/method2.PNG)

> 假设条件：
> - 假设企业每年仅招应届本科+硕士 （考虑社招极少，博士占比低， 忽略此因素影响后，可以控制每年的输入，仅为30-部分的增量，即X1，X2...，大大简化建模复杂度）
> - 假设n1，n2，n3均为0 （考虑50+的基数小，变化绝对值极小，实际运算省略后，简化建模复杂度）

如图示例：
报告时间年度如：T1，T2，T3...
T1年份新入职人数为：X1
T1年份各年龄区间离职/退休人数为：a1，b1，c1
T1进入T2年份，因年龄自然增长（即29->30，50->51），而产生的统计迁移数为：m1，n1

带入2013/2014等年度数据到演示图，可知：
```
X1+58800-a1-m1=62730
m1+89130-b1=104720
```
运算可得：
```
m1=104720-89130+b1
X1=62730-58800+a1+m1
```
而
```
62730-58800是两个相邻年30-区间的差值，记为δ1
104720-89130是两个相邻年30-50区间的差值，记为δ2
```
最终可知：
```
m1=δ2+b1（以此类推，m2=δx+b2，m3=δy+b3）
X1=δ1+a1+m1=δ1+a1+δ2+b1（也一样可以类推下去）
```

### 5. 初始参数
假设的初始参数（用于宏观定调，支持程序初始阶段拟合）
```
离职率1（新员工入职1年期离职率）：10%，10%，10%...(每年)
离职率2（初新员工外的整体离职率）：5%，10%，10%...(每年)
```

### 6. 拟合参数
用于拟合的正式参数（正式的精细化参数，用于后继程序暴力拟合）
```
新员工离职率（新员工入职1年期离职率，与上述离职率1独立）：10%，10%，10%...(每年)
34-迭代离职率（考虑35岁的区分设置）：5%，5%，5%...(每年)
35+迭代离职率（考虑35岁的区分设置）：5%，5%，5%...(每年)
41+迭代退出率（含离职，含退休，考虑40岁的亚健康退休线）：5%，5%，5%...(每年)
46+迭代退出率（含离职，含退休，考虑45岁的退休线）：5%，5%，5%...(每年)
应届本科率1（记为22岁入职新员工）：15%，15%，15%...(每年)
```

### 7. 等效参数
基于上述初始参数和拟合参数，结合前述假设公式，可以得到等效变量参数：
```
初始29岁年龄段人数：20527, 11526, 19791…(每年)（对应示意图的m1，m2…，随初始参数变化而变化）
初始应届新员工总数：10000, 28913, 10427…(每年)（对应示意图的X1，X2…，随初始参数变化而变化）（首年10000为数据边界保护，不影响最终计算）
应届本科率2（记为23岁入职新员工）：7%，7%，7%...(每年)（考虑每年9.1作为入学分界线，按均匀出生分布，则本科毕业人群中22岁占比2/3，23岁占比1/3，这里7%用整除）
应届硕士率1（记为25岁入职新员工）：52%，52%，52%...(每年)（已忽略博士，应届入职仅考虑本科与硕士，则剩余占比中，取2/3为25岁，取1/3为26岁）
应届硕士率2（记为26岁入职新员工）：26%，26%，26%...(每年)（同上，取剩下的占比即可）
```

基于理论依据(1)，结合以上参数、假设条件、计算方法，可在一张[年龄段X年份]的表格中，进行数据推演，理论上计算可以得到表格的右上三角部分数据；即：

### 9. Loss设置
实际详细排列推演表后，排除2013年的边界值，排除2024年最终结果值，可以取2021/2022/2023这3年的数据中的29岁值以及30-的值，作为验证值，即：
```
Loss1: 基于宏观定调的初始参数计算得到的21/22/23这3年的29岁年龄段人数，作为标准值；基于拟合参数逐年推演得到的21/22/23这3年的29岁年龄段人数作为测算值，取三年的[(标准值-测算值)/标准值]之和
Loss2: 基于公开数据计算的21/22/23这3年的准确的30-的值，作为标准值；基于拟合参数逐年推演得到的21/22/23这3年的30-的年龄段人数求和，取三年的[(标准值-测算值)/标准值]之和
```
最终，通过设置大范围寻参，如```34-迭代离职率，设置每年range(1,20,1)```，让程序暴力计算和拟合数据，让Loss1和Loss2均达到一个合理低值（仍需要结合主观分析，判断多个低loss与数据本身合理性之间的取舍），即可得到最终结果


## 三. 拟合程序
项目程序结构介绍：
- **getAge_BASE**：静态数据、初始变量等
- **getAge_GEN**：调参文件，设定各个参数的组合范围
- **getAge_DATA**：封装的主要数据计算类，根据输入的参数，推演表格中的年龄变化，得到表格的右上三角数据
- **getAge_LOSS**：计算与监控loss
- **getAge_MAIN**：主程序，做大循环暴力寻参即输出进度
